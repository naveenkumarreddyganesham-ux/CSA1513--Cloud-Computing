💻 C Program - Display Student Information

The following C program can be executed using a C compiler. This web application demonstrates how the student information system can be provided as a cloud-based SaaS interface.

#include <stdio.h> int main() { char name[50]; int regno, age; printf("Enter Student Name: "); scanf("%s", name); printf("Enter Register Number: "); scanf("%d", &regno); printf("Enter Age: "); scanf("%d", &age); printf("\n--- Student Information ---\n"); printf("Name: %s\n", name); printf("Register Number: %d\n", regno); printf("Age: %d\n", age); return 0; }
